## 5. 页面级资产

每款产品至少需要：

- 应用图标：SVG 或 1024×1024 PNG。
- 产品截图：至少覆盖手机主路径；若支持平板和桌面，分别提供代表性截图。
- 截图说明：避免只展示 UI 而不解释价值。
- 商店链接和地区可用性。
- 当前支持的最低系统版本。
- 公开版本号或是否不展示版本号的决定。
- 支持邮箱、反馈链接和 FAQ。
- 隐私政策的生效日期、最后更新日期和事实确认人。

## 6. 内容验收规则

- 事实优先于营销表达；平台、功能、价格、同步和加密声明必须可验证。
- 不使用“绝对安全”“永不丢失”等无法保证的表述。
- 同一产品的名称、下载链接、系统要求和联系邮箱只维护一个数据源。
- 中文与英文内容应表达同一事实，不以机器直译直接上线。
- 法律文本发布前需由实际责任人确认；网站实现只负责准确呈现，不代替法律审查。
- 仓库与发布站点均为公开环境，内容文件、构建产物、提交历史和前端代码中均不得包含敏感信息。
